# Radar de rupturas

Dashboard que se actualiza solo y se publica en GitHub Pages.

- **Ver el dashboard:** https://TU-USUARIO.github.io/radar/
- **Cambiar criterios:** editá la sección CONFIGURACIÓN al principio de `radar.py` desde la web de GitHub (ícono del lápiz → Commit changes).
- **Actualizar ya mismo:** pestaña Actions → "Actualizar radar" → Run workflow.

Horarios automáticos: cada hora de 11 a 17 h (Argentina) de lunes a viernes, a las 18:30 después del cierre y los sábados al mediodía.
Durante la rueda, la vela diaria es la del día en curso.
